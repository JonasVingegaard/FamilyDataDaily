## 快速开始

### 1. 下载项目

将整个 `FamilyDataDaily` 文件夹放到任意目录。

### 2. 安装依赖

```bash
# 进入项目目录
cd FamilyDataDaily

# 安装依赖
pip install Flask==3.0.0 Werkzeug==3.0.1
```

### 3. 启动服务器

```bash
python app.py
```

启动成功后会显示：

```
============================================================
🏠 家庭日记系统启动成功！
============================================================
📍 本机访问: http://localhost:5000
📍 局域网访问: http://192.168.x.x:5000
📱 手机/平板访问: http://192.168.x.x:5000
============================================================
```

### 4. 访问系统

- **本机**：打开浏览器访问 `http://localhost:5000`
- **其他设备**：确保在同一局域网，访问 `http://192.168.x.x:5000`（替换为实际 IP）

## 使用指南

### 注册账号

1. 访问系统首页，点击 **"注册新账号"**
2. 填写信息：
   - **用户名**：2-20 个字符
   - **邮箱**：有效的邮箱地址
   - **密码**：建议 6 位以上
   - **确认密码**：再次输入密码
3. 点击 **"注册"** 按钮
4. 注册成功后自动跳转到登录页

### 登录

1. 在登录页输入用户名和密码
2. 点击 **"登录"** 按钮
3. 登录成功后进入主页面

### 忘记密码

1. 在登录页点击 **"忘记密码？"**
2. 输入用户名提交
3. 联系管理员在服务器上重置密码（见[密码管理](#密码管理)）

---

### 主页面功能

登录后进入主页面，左侧有导航栏，包含 4 个功能页面：

#### 📖 公共日记（查看）
- 查看所有家庭成员发布的公共日记
- 以卡片形式展示，包含文字、图片、视频、附件
- 可以点击刷新按钮获取最新内容

#### 🔒 我的日记（查看）
- 仅查看自己发布的私密日记
- 可以删除自己的日记（点击"🗑️ 删除"按钮）

#### ✍️ 写公共日记
- 填写日期（支持三种方式）：
  - 点击 **"今天"** 按钮一键选择
  - 使用日期选择器
  - 手动输入 `YYYY-MM-DD` 格式
- 输入文字内容
- 上传图片（支持 png, jpg, jpeg, gif）
- 上传视频（支持 mp4, avi, mov）
- 上传其他文件（支持 pdf, doc, docx, txt）
- 点击 **"💾 保存日记"** 提交

#### 📝 写私密日记
- 与公共日记功能相同，但仅自己可见

## 密码管理

### 命令行工具

在服务器终端中运行：

```bash
# 查看所有用户
python manage_password.py list

# 查看指定用户信息
python manage_password.py get <用户名>

# 重置用户密码
python manage_password.py reset <用户名> <新密码>
```

示例：
```bash
python manage_password.py reset 张三 123456
```

### 通过管理员后台

1. 用管理员账号登录
2. 进入"管理员后台" → "用户管理"
3. 找到目标用户，点击"重置密码"
4. 输入新密码，点击确认

## 常见问题

### Q: 无法访问系统？

**A:** 检查以下几点：
1. 服务器是否已启动（终端是否显示启动成功）
2. 防火墙是否允许 5000 端口：`sudo ufw allow 5000`
3. 手机/平板是否与服务器在同一局域网


### Q: 文件上传失败？

**A:** 
1. 检查文件大小是否超过 100MB
2. 检查文件格式是否在允许列表中（png, jpg, jpeg, gif, mp4, avi, mov, pdf, doc, docx, txt）
3. 检查 `data/` 目录是否有写入权限

### Q: 忘记管理员密码？

**A:** 在服务器终端运行：
```bash
python manage_password.py reset admin 新密码
```

### Q: 如何备份数据？

**A:** 备份整个 `data/` 文件夹即可：
```bash
cp -r data/ data_backup_2026/
```

### Q: 如何修改端口？

**A:** 编辑 `app.py` 文件，找到 `port = 5000`，改为其他端口号。

### Q: 支持多少用户同时在线？

**A:** 设计支持 ≤15 个用户同时在线（局域网环境）。

### Q: 数据存储在哪里？

**A:** 
- 数据库：`data/family_diary.db`（SQLite）
- 上传文件：`data/uploads/`
- 所有数据以明文存储，方便备份和迁移
